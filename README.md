# Dijitali Maths

**Making Mathematics Digital, Accessible, and Inspiring.**

Dijitali Maths is a mathematics-focused initiative dedicated to making mathematics more engaging, accessible, and practical for learners, teachers, and communities.

This repository contains the official website for **Dijitali Maths**, showcasing the organization's work, projects, events, resources, impact, partners, and opportunities for people to get involved.

## 🌍 About Dijitali Maths

Dijitali Maths uses digital tools, innovative learning approaches, community activities, and teacher engagement to help improve mathematics learning and create stronger opportunities for learners.

Our work focuses on:

* 📚 Mathematics education and learning
* 💻 Digital mathematics resources
* 👩‍🏫 Teacher training and support
* 🧮 Mathematics activities and competitions
* 🌱 Community-based learning initiatives
* 🚀 STEM and digital skills
* 🤝 Partnerships and collaboration
* 📊 Measuring educational and community impact

## 💻 Running the Website Locally

Because this is a static website, no backend server is required for the basic version.

### Option 1: Open directly

Clone the repository:

```bash
git clone https://github.com/Kenshitawa/dijitali_maths.git
```

Enter the project:

```bash
cd dijitali_maths
```

Then open:

```text
index.html
```

in your browser.

### Option 2: Use VS Code

Open the project folder in Visual Studio Code and use the **Live Server** extension to launch the website locally.
